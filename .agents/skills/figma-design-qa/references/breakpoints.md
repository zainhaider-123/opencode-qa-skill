# Required Responsive Test Breakpoints

Test the live site at every one of these. Do not skip any, do not substitute different sizes.

## Desktop
- 1280x720
- 1366x768
- 1400x900
- 1440x900
- 1536x864
- 1600x900
- 1680x1050
- 1792x1120
- 1920x1080
- 2048x1536
- 2560x1440

## iPad
- 768x1024
- 810x1180
- 1024x1366

## Mobile
- 360x740
- 412x915
- 430x932
- 375x740

## What to check at each size
- Font sizes don't cause text/element overflow or clipping.
- All sections and their content remain visible and reachable.
- Spacing between sections still looks intentional (no overlap, no oversized accidental gaps).
- Mobile only: hamburger menu opens and reveals the same links as the desktop nav.
